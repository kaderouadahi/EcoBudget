# H0 Socle — Plan d'implémentation

> **Pour l'exécutant :** SOUS-SKILL REQUIS : superpowers:executing-plans (choisi par Kader). TDD (superpowers:test-driven-development) pour `format.ts` et `month.ts`. superpowers:verification-before-completion avant de déclarer H0 terminée. Étapes en cases à cocher.

**Objectif :** poser l'application installable (PWA) EcoBudget : compte anonyme silencieux, Firestore hors connexion, règles « chacun ses données » testées à l'émulateur, navigation téléphone/ordinateur, charte, formats DA/dates, message de confirmation commun ; déployée sur Firebase Hosting.

**Architecture :** SPA React + Vite + TypeScript dans `app/`. Firebase initialisé une fois (`src/firebase.ts`) avec cache Firestore persistant ; toutes les données sous `users/{uid}/…`. Écritures « fire-and-forget » (id généré côté client, `setDoc` non attendu) pour que l'UI se mette à jour hors connexion via `onSnapshot`. Une seule liste `NAV_ITEMS` alimente la barre du bas et la barre latérale ; seule la CSS (point de rupture 900 px) change la disposition.

**Stack :** React 19, Vite, TypeScript, react-router-dom, vite-plugin-pwa (+ @vite-pwa/assets-generator), firebase (JS SDK modulaire), lucide-react (icônes, celles des maquettes), @fontsource/plus-jakarta-sans (police embarquée, donc hors connexion), Vitest + Testing Library + jsdom, @firebase/rules-unit-testing. CSS simple avec variables (pas de framework). Graphiques (H6) : **Recharts** — consigné dans « Écarts constatés » de H0.

**Spec :** `docs/HANDOFF.md` § H0 ; `docs/DECISIONS.md` (prime sur les maquettes) ; `docs/02_maquettes/`.

## Modèle de données (choix Claude Code, autorisé par la spec)
Dates stockées en chaîne locale `YYYY-MM-DD`, mois en `YYYY-MM` (aucun piège de fuseau). `createdAt: number` (ms, client) pour l'ordre.
```
users/{uid}                      UserDoc  { firstName?: string, alertsEnabled: boolean, adviceEnabled: boolean,
                                            adviceHiddenUntil?: string /*YYYY-MM*/, onboardingDone: boolean }
users/{uid}/categories/{id}      Category { name, icon /*nom lucide*/, order: number, locked: boolean /*Autres*/ }
users/{uid}/expenses/{id}        Expense  { amount: number /*entier DA*/, categoryId, date /*YYYY-MM-DD*/, note?: string, createdAt }
users/{uid}/budgets/{categoryId} Budget   { amount: number }        // reconduit : pas de mois dans la clé
users/{uid}/goals/{id}           Goal     { name, target: number, targetMonth /*YYYY-MM*/, createdAt }
users/{uid}/contributions/{id}   Contribution { goalId, amount: number, date, createdAt }
```

## Points d'attention (Review Focus)
1. **Première ouverture sans réseau** : `signInAnonymously` échoue → écran « Connectez-vous à internet une fois pour commencer » et nouvel essai automatique sur l'événement `online` (pas d'écran blanc). Test : `AuthGate.test.tsx`.
2. **Écriture hors connexion qui « bloque »** : un `await setDoc` ne se résout qu'à l'accusé du serveur. `createDoc`/`updateDocFields`/`removeDoc` ne doivent jamais être attendus par l'UI ; ils renvoient l'id tout de suite. Vérification manuelle (Tâche 6).
3. **Montants négatifs, zéro, très grands** : `formatDA(-250)` → « −250 DA » (signe moins U+2212), `formatDA(0)` → « 0 DA », `formatDA(1234567)` → « 1 234 567 DA ». Tests dans la Tâche 2.
4. **Bornes de mois** : 31 janvier → 1er février, février bissextile, 31 décembre → janvier suivant. Tests dans la Tâche 2.
5. **Deux onglets ouverts** : cache persistant avec `persistentMultipleTabManager()` pour éviter l'erreur « failed-precondition ».

### Tâche 2 : Formats et mois (TDD)

**Fichiers :** `app/src/lib/format.ts`, `app/src/lib/format.test.ts`, `app/src/lib/month.ts`, `app/src/lib/month.test.ts`.

**Produit :**
- `formatDA(amount: number): string` — séparateur de milliers U+202F (espace fine insécable), U+00A0 avant « DA », négatif préfixé U+2212.
- `formatDay(iso: string, today: Date): string` — « Aujourd'hui » ; « Hier » ; de 2 à 6 jours avant : jour de la semaine avec majuscule (« Samedi », comme la maquette) ; sinon `Intl.DateTimeFormat('fr-FR', {weekday:'long', day:'numeric', month:'long'})` → « samedi 14 novembre » (+ année si différente de celle de `today`).
- `formatMonthTitle(month: string): string` → « Novembre 2026 » ; `monthName(month: string): string` → « novembre ».
- `toISODate(d: Date): string` (date locale), `monthOf(iso: string): string`, `currentMonth(today: Date): string`, `addMonths(month: string, n: number): string`, `daysLeftInMonth(today: Date): number` (jour courant inclus : 18 nov. → 13), `isInMonth(iso: string, month: string): boolean`.

- [ ] Écrire les tests (valeurs exactes, avec ` `/` `/`−`) :
  - `formatDA(34000) === '34 000 DA'`, `formatDA(250) === '250 DA'`, `formatDA(0) === '0 DA'`, `formatDA(1234567) === '1 234 567 DA'`, `formatDA(-250) === '−250 DA'`.
  - avec `today = new Date(2026, 10, 19)` (jeudi) : `formatDay('2026-11-19')` → « Aujourd'hui » ; `'2026-11-18'` → « Hier » ; `'2026-11-14'` → « Samedi » ; `'2026-11-01'` → « dimanche 1 novembre » ; `'2025-12-24'` → « mercredi 24 décembre 2025 ».
  - `formatMonthTitle('2026-11') === 'Novembre 2026'`, `monthName('2026-11') === 'novembre'`.
  - `daysLeftInMonth(new Date(2026,10,18)) === 13`, `(new Date(2026,10,30)) === 1`, `(new Date(2028,1,1)) === 29`.
  - `addMonths('2026-12', 1) === '2027-01'`, `addMonths('2026-01', -1) === '2025-12'`, `addMonths('2026-01', 1) === '2026-02'`.
  - `isInMonth('2026-11-30','2026-11') === true`, `isInMonth('2026-12-01','2026-11') === false` ; `toISODate(new Date(2026,0,31)) === '2026-01-31'`.
