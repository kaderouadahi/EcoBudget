## Contraintes globales (valeurs de la spec)
- Sections dans l'ordre Compte, Catégories, Alertes et conseils ; ordinateur ≥ 1100 px : deux colonnes (Compte à gauche, Catégories puis Alertes à droite).
- Compte : icône nuage, « Sans compte », « Vos données sont enregistrées de façon anonyme sur cet appareil. » ; pas de boutons de compte. « Votre prénom (facultatif) », aide « Affiché sur l'accueil : « Bonjour [prénom] » » (« Bonjour » si vide) ; enregistré en quittant le champ ou avec Entrée ; espaces retirés ; « Prénom enregistré » seulement si changé ; vide → effacé ; **30 caractères au plus** (choix, à noter dans les écarts).
- Catégories : ordre des catégories ; crayon « Modifier [nom] », corbeille **grise** « Supprimer [nom] » ; « Autres » en dernier, cadenas, « Toujours présente », sans crayon ni corbeille ; bouton « Ajouter une catégorie ».
- Nom : obligatoire, ≤ 20 caractères ; « Donnez un nom à la catégorie, par exemple Enfants » ; « Cette catégorie existe déjà » (majuscules et espaces ignorés ; son propre nom accepté en modification) ; trop long : « 20 caractères au plus ».
- Icônes proposées : `CATEGORY_ICONS` sans `Ellipsis` (Autres) ni l'alias `UtensilsCrossed` ; noms accessibles (« Couverts », « Panier », « Bus », « Ticket », « Cœur », « Maison », « Livre », « Bébé », « Cadeau », « Vêtement », « Téléphone », « Voiture », « Animal », « Sport », « Avion », « Outil ») ; présélection : la première non utilisée (en modification, l'actuelle).
- Nouvelle catégorie : `order` = plus grand ordre hors « Autres » + 1 (avant « Autres », ordre 99).
- Messages : « Catégorie ajoutée : Enfants » / « Catégorie modifiée » avec « Annuler » ; « Catégorie supprimée : Sorties · 12 dépenses déplacées vers Autres » (« 1 dépense déplacée ») avec « Annuler » ; « Prénom enregistré » ; « Alertes désactivées / activées », « Conseils désactivés / activés » sans « Annuler ».
- Suppression : « Supprimer la catégorie Sorties ? » ; « Les 12 dépenses de Sorties ne seront pas perdues : elles seront déplacées dans la catégorie choisie ci-dessous. » (une seule : « La dépense de Sorties ne sera pas perdue : elle sera déplacée dans la catégorie choisie ci-dessous. ») ; sans dépense : « Aucune dépense dans Sorties. » sans menu ; avec budget : « Le budget de Sorties sera supprimé. » ; puis « Vous pourrez l'annuler juste après. » ; menu « Déplacer les dépenses vers », Autres puis les autres catégories dans leur ordre. Toutes les dépenses déplacées (tous mois) en un `applyBatch` ; « Annuler » rétablit catégorie (même id, nom, icône, ordre), budget, et seulement les dépenses déplacées.
- Interrupteurs : `role="switch"`, texte « Activé » / « Désactivé » ; effet immédiat (`setUserFields`) ; alertes désactivées → carte d'alerte masquée, revient à la réactivation si la dépense n'a pas changé. « Gérer les alertes / les conseils » → `/reglages#alertes`, section amenée à l'écran.

## Review Focus
1. Catégorie supprimée alors qu'une alerte porte sur une de ses dépenses : la carte disparaît (catégorie changée), « Annuler » la fait revenir (règle `visibleAlert`). Test lot 3.

4. `/reglages/categories/autres` (URL tapée) : pas de modification possible d'« Autres » (retour aux Réglages). Lot 2.
5. Prénom de 30 caractères ou avec espaces : affiché tronqué proprement sur l'Accueil (pas de débordement). Vérif navigateur.
