# H2 Budgets — Plan d'implémentation

> superpowers:executing-plans ; TDD pour `lib/budget.ts` ; verification-before-completion avant « fait ».

**Objectif :** Budget mensuel facultatif par catégorie, reconduit, modifiable, retirable (confirmation + « Annuler ») ; état couleur + icône + texte ; reste à dépenser et « Hors budget » sur l'Accueil ; écran Budgets et détail.
**Spec :** `docs/HANDOFF.md` § H2 ; DECISIONS.md (17/11 état et budgets) ; maquettes `telephone-02`, `telephone-04`, `ordinateur-02`, `ordinateur-04`.
**Modèle :** `users/{uid}/budgets/{categoryId}` `{ amount }` (H0) : pas de mois dans la clé, donc reconduit d'office.

## Review Focus
1. Budget sur une catégorie supprimée (H7) : ignoré dans les totaux (pas de ligne fantôme).
2. Dépense d'un autre mois : hors des calculs du mois.
3. Reste exactement 0 : « 0 DA », pas « dépassé ».
4. Montant du budget « 2,5 », « 0 », vide : refusé au champ, mêmes messages que Montant d'une dépense.
5. Barre de progression au-delà de 100 % : bornée à 100 %.

### Tâche 1 : calculs (TDD) — `src/lib/budget.ts`
- `spentByCategory(expenses, month): Map<string, number>`
- `budgetSummary(budgets, categories, expenses, month)` → `{ rows: { categoryId, amount, spent, kind, remaining, percent }[] (ordre des catégories), offBudget: { categoryId, spent }[] (spent > 0, décroissant), totalBudget, spentInBudgets, remaining, spentTotal }`
- `percent(spent, budget)` arrondi ; `barRatio` borné 0..1.
- `headline(summary, monthName)` → aucun budget : `{ label: 'Dépensé ce mois', value: spentTotal, tone: 'neutral' }` ; reste < 0 : `{ label: 'Budgets dépassés de', value: -remaining, tone: 'danger' }` ; sinon `{ label: 'Reste à dépenser en novembre', value: remaining, tone: 'neutral' }`.
Tests (CLAUDE.md §9) : états 79/80/100/101 (déjà) ; reste avec et sans hors budget ; reste négatif ; aucun budget ; autre mois exclu ; catégorie disparue ignorée.

### Tâche 2 : composants — `src/features/budgets/BudgetCard.tsx`, `StatusChip.tsx`
StatusChip : ok → Check « Dans le budget » (vert) ; warn → TriangleAlert « Il reste X DA » (orange) ; over → CircleAlert « Dépassé de X DA » (rouge). BudgetCard : icône, nom, « X DA sur Y DA », barre, puce, lien vers le détail. Test : chaque état a icône + texte (jamais la couleur seule).

### Tâche 3 : écrans — Budgets, détail, formulaire
Routes : `/budgets`, `/budgets/:categoryId`, `/budgets/fixer` (?categorie=), `/budgets/:categoryId/modifier`.
- Budgets : titre + mois, cartes, « Hors budget : Santé 1 800 DA », « Fixer un budget pour une catégorie » (masqué si toutes en ont un), invitation si aucun.
- Détail : carte avec montant, %, état, « Modifier », « Budget reconduit chaque mois. Vous pouvez le changer à tout moment. », dernières dépenses de la catégorie ce mois (ExpenseList).
- BudgetForm : catégorie (seulement en création, catégories sans budget), montant (parseAmount), aide, « Enregistrer le budget » ; en modification « Retirer le budget » → ConfirmDialog (« Retirer le budget Courses ? » / « Ses dépenses passeront en Hors budget. ») → « Budget retiré » + Annuler. Messages : « Budget fixé : Courses, 40 000 DA par mois » / « Budget modifié » + Annuler.
Test BudgetForm : montant invalide bloqué au champ ; valeurs valides envoyées.

### Tâche 4 : Accueil
Carte bleu nuit (headline, « sur X DA de budgets · N jours restants », barre), « Vos budgets » + « Tout voir », Hors budget, Dernières dépenses ; deux colonnes sur ordinateur. Invitation « Fixer un budget » si aucun budget.
