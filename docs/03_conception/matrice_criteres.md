# Matrice de traçabilité — critères de Bastien et Scapin

Une ligne = un élément concret de l'application. Sous-critères de la grille classique, à aligner sur le cours.
Les pistes sont des propositions à valider.

| Critère | Sous-critères | Pistes pour EcoBudget | Écran(s) | Preuve | Statut |
|---|---|---|---|---|---|
| C1 Guidage | Incitation, groupement/distinction, feedback immédiat, lisibilité | Exemples dans les champs ; regroupement par mois et catégorie ; confirmation visible après ajout | | | |
| C2 Charge de travail | Brièveté, densité informationnelle | Ajout d'une dépense en très peu d'actions ; catégorie suggérée ; accueil limité à l'essentiel | | | |
| C3 Contrôle explicite | Actions explicites, contrôle utilisateur | Rien n'est appliqué sans accord ; Annuler ; innovation désactivable | | | |
| C4 Adaptabilité | Flexibilité, prise en compte de l'expérience | Mode simple / avancé ; catégories et seuils personnalisables | | | |
| C5 Gestion des erreurs | Protection, qualité des messages, correction | Saisies invalides bloquées au bon champ ; messages qui disent quoi faire ; modification possible | | | |
| C6 Homogénéité | — | Mêmes composants, positions et libellés partout, sur mobile et ordinateur | | | |
| C7 Signifiance | — | Icônes de catégories compréhensibles ; couleur + texte ; vocabulaire non bancaire | | | |
| C8 Compatibilité | — | Formats de date et de montant locaux ; mois budgétaire réglable ; usage en déplacement | | | |
