# Fonctionnalité innovante — fiche de conception

**Sujet :** recommandations ou détection de dépenses inhabituelles, dans une interface simple et compréhensible.
**Décidé (voir DECISIONS.md) :** alerte de dépense inhabituelle, puis conseil, calculés par règles statistiques explicables.

## 1. Besoin réel adressé
À remplir depuis l'analyse des besoins (citations réelles d'entretiens).

## 2. Comportement attendu
- **Alerte** : quand une dépense ou un rythme de dépenses sort des habitudes.
- **Conseil** : une action concrète et chiffrée, issue des mêmes données.
- **Pourquoi ?** : la comparaison expliquée en une phrase.
- **Contrôle** : accepter, ignorer, « ce n'est pas inhabituel », désactiver.

## 4. Au-delà du classique (§8)

## 5. Démonstration
Données de démo qui déclenchent l'alerte de façon reproductible ; script de démo court.
